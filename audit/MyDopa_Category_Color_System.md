# MyDopa Category Color System v1

**Status:** Authoritative. Effective August 7, 2026, forward-only.
**Purpose:** Single source of truth for Brain Lab category-tag colors (`.article-category` value in the canonical HTML template). Every cluster below gets exactly one fixed hex, applied consistently across all new articles.

Category-tag colors are a **distinct identification layer**, separate from the core MyDopa Brand Identity Reference palette (purple/orange). Multi-color category tags are an intentional design decision, not a deviation from brand.

Do not invent new colors outside this table. Do not inherit a category color automatically from the canonical HTML master file — always pull the correct hex for the article's actual cluster from this table.

New clusters added to the register must receive an assigned color here **before** their first article publishes.

This file governs forward production only. It does not reconcile or retroactively correct category colors on articles published before August 7, 2026.
