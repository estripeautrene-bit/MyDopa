**The Governing Sentence Rule**

This rule does not expire. It applies to every person who works on MyDopa — designers, developers, writers, AI systems, and the founder. It is not a guideline. It is a constraint.

|  |
| --- |
| **THE GOVERNING SENTENCE Your day is already full of wins. You are just not keeping them. MyDopa fixes that.** |

**What this sentence is**

This is not a tagline. A tagline speaks to people who already understand the product. This sentence speaks to people who have never heard of MyDopa and makes them feel seen before they know what it is. That is why it converts where taglines do not.

It does three things in three sentences:

|  |  |
| --- | --- |
| **Your day is already full of wins.** | Names the reality the person is living right now. Affirms their life before they have done anything. No problem framing. No shame. Pure recognition. |

|  |  |
| --- | --- |
| **You are just not keeping them.** | Names the exact gap — not a character flaw, not laziness, not failure. The brain is the problem. The person is fine. This one sentence removes all self-blame. |

|  |  |
| --- | --- |
| **MyDopa fixes that.** | Three words. No feature list. No explanation. The product is the solution to the gap that was just named. Nothing more needs to be said. |

**The rule**

|  |
| --- |
| **Every MyDopa screen that asks someone to make a decision — to download, to subscribe, to start, to return, to believe — must have this sentence visible before they decide.** |

This is not decoration. It is the conversion mechanism. The sentence replaces the need to explain what MyDopa is, why it exists, or why the person should care. It does all three things in 20 words.

**Where it goes**

**MANDATORY — No exceptions**

* App Store screenshots — Screen 1 or Screen 2. Before the paywall. Always.
* Homepage hero — First thing a visitor reads. Above the fold. Full sentence.
* Onboarding welcome screen — The first screen after the user opens the app for the first time.
* Paywall screen — Directly above or below the subscription offer. The sentence is what makes the price feel justified.
* Email subject lines or email header — Every outbound email from MyDopa traces back to this sentence. The welcome email opens with it.
* Instagram and TikTok bio — One version of this sentence lives permanently in the bio of every MyDopa account.

**RECOMMENDED — Use whenever possible**

* Push notifications that ask the user to return to the app
* Re-engagement emails sent after a user has been inactive
* The DOPA AI companion's first message to a new user
* Any paid ad creative where the product needs to be introduced
* Influencer brief — the sentence is what the influencer is explaining in their own words
* Press and media kit — the first sentence any journalist reads about MyDopa

**How to use it**

The sentence does not need to appear word-for-word every time. It needs to be the idea behind every conversion surface. When writing any piece of copy for MyDopa, ask:

|  |
| --- |
| **Does this copy make the person feel seen before it asks them to do anything? If the answer is no — rewrite it until the answer is yes.** |

**What this sentence is NOT**

* Do not rewrite it to be shorter. It is already as short as it can be while doing its job.
* Do not replace it with a feature description. Features do not convert people. Recognition converts people.
* Do not lead with the science. The science is the proof. This sentence is the feeling. Feeling comes first.
* Do not use it as a footer or small print. It is a headline. It lives at the top, not the bottom.
* Do not let any screen that asks for money, a download, or a commitment go live without it.

**Why it works — the evidence**

Ahead — MyDopa's reference product with 3.5 million users — built its entire acquisition system around one insight: the moment a person feels seen, they stop scrolling.

MyDopa's governing sentence does something more powerful. It does not require the person to know what Duolingo is, what emotional intelligence is, or what MyDopa does. It describes their life. A person reads "your day is already full of wins" and they think about the gym session they did not appreciate, the call that went well and was immediately forgotten, the quiet Tuesday that was actually pretty good. They feel recognized. That recognition is the conversion.

Research on consumer conversion consistently confirms that recognition outperforms explanation. This sentence recognizes. It does not explain. That is why it goes first, goes everywhere, and never gets replaced.

**The companion rules**

|  |  |
| --- | --- |
| **Positives only** | Every sentence affirms, celebrates, or looks forward. Zero negations. Zero absence framing. MyDopa speaks only in what is, not in what is not. |

|  |  |
| --- | --- |
| **Human language only** | No percentages, no ratios, no framework language. Write the way a person actually talks. "You did the thing" not "you achieved a 94% completion rate." |

|  |  |
| --- | --- |
| **Science as proof, not headline** | Lead with the feeling or the destination. Science follows as the reason to believe. Never open a screen or email with research. Open with the person. |

|  |  |
| --- | --- |
| **Mental performance, not mental health** | MyDopa is mental performance. Mental resilience. Magnetic confidence. Never mental health. Never therapy. Never wellness in the clinical sense. |

|  |  |
| --- | --- |
| **Earned praise only** | MyDopa only celebrates what the user actually did. Generic praise breaks trust. Specificity creates credibility. |

|  |  |
| --- | --- |
| **Forward always** | Even when referencing the past, the orientation is today and tomorrow. "You built something real. It is still here." Never backward-looking. Never regret-framing. |
